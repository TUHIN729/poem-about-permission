A short poem about agency — the power to ask and to be given — written in the
voice of an AI agent asking its person for the power to act on their behalf,
and being given it. One small yes, and a door that only knocking could not open.

`main.ts` (Node 22+, standard library only, no network at runtime) writes the
poem to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`), byte-identical
on every run.
